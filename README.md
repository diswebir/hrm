# سامانه منابع انسانی (HRM)

سامانه جامع مدیریت منابع انسانی با **PHP خالص** و **دیتابیس SQLite** — طراحی‌شده برای میزبانی اشتراکی cPanel؛ بدون Composer، بدون MySQL، بدون نیاز به خط فرمان.

> 📖 **۱۱۸ قابلیت** با مستندات کامل و آموزش گام‌به‌گام در بخش **«درباره سامانه»** داخل خود سامانه ثبت و مستند شده است.

## 🚀 نصب روی cPanel

1. محتوای همین مخزن را در `public_html/hrm` (یا هر مسیر دلخواه) آپلود کنید.
2. دامنه/مسیر را در مرورگر باز کنید — `install.php` به‌طور خودکار اجرا می‌شود.
3. ویزارد ۵ مرحله‌ای را دنبال کنید (بررسی محیط ← اطلاعات سازمان ← ساخت مدیر ← دیتابیس ← پایان).
4. وارد شوید: نام کاربری و رمزی که در گام ۳ ساختید.

**پیش‌نیاز:** PHP 7.4+ با افزونه `pdo_sqlite` (پیش‌فرض همه هاست‌های cPanel).

> پس از نصب، `install.php` قفل می‌شود. دیتابیس در `storage/database/hrm.sqlite` قرار دارد.

## 🖥 اجرای محلی (برای توسعه)

```bash
php -S localhost:8000 router.php   # یا هر سرور PHP با document root ریشه پروژه
```

## 📁 ساختار

```
install.php          — نصب‌کننده وب (پس از نصب غیرفعال می‌شود)
config/              — پیکربندی (config.php پس از نصب ساخته می‌شود)
install/             — اسکیمای SQL و داده‌های نمونه (Seeder)
app/core/            — هسته: Router، DB، Auth، Csrf، Jalali (تقویم شمسی)، …
app/controllers/     — کنترلرها
app/routes.php       — نقشه مسیرها
views/               — قالب‌های فارسی RTL
assets/              — CSS/JS بدون وابستگی خارجی
storage/             — دیتابیس، نشست‌ها، لاگ، آپلودها، پشتیبان‌ها (محافظت‌شده با .htaccess)
```

## 🔒 امنیت

- محافظت `app/`، `config/`، `storage/`، `install/` با `.htaccess` (deny)
- توکن CSRF روی همه فرم‌ها، خروجی escape شده (XSS)، Prepared Statements (SQLi)
- رمزها با `password_hash` (bcrypt)، قفل حساب پس از ۵ ورود ناموفق
- تقویم شمسی بومی و دقیق (تأییدشده در برابر کتابخانه jalaali-js)
